FinXSystems Knowledge Intelligence Platform (FKIP) System Architecture Log
==========================================================================
Date: 2026-07-16
Author: Core Engineering Team

1. Microservices Setup
----------------------
The FKIP platform employs a multi-container Docker cluster environment.
- PostgreSQL runs on port 5432 and stores users, audit logs, Oracle relations, and backlog items.
- Weaviate acts as the core Vector Store, listening on port 8081 for REST API requests.
- Ollama is the private local AI engine running on port 11434, loading 'qwen2:0.5b' and 'all-minilm'.
- The FastAPI Backend exposes API endpoints on port 8000.
- The React SPA Frontend provides user console views on port 5173.

2. Document Ingestion Pipeline
-----------------------------
Unstructured files (PDF, DOCX, TXT, CSV) are parsed on upload. Chunks are generated (max 500 characters, 100 characters overlap), vectorized by the Ollama embedding client, and saved as DocumentChunk collections inside Weaviate.

3. Core Functional Scopes
-------------------------
- RAG Assistant: Performs near-vector semantic fetches to feed the context prompt structure.
- Oracle Intelligence: Parses SQL DDL, maps views/triggers, and lists downstream impact trace logs.
- Core Banking: Computes cosine distances on app capabilities to find feature duplicates.
- Innovation Backlog: Promotes feature opportunity tickets to the project Kanban board.
- Connected Knowledge Graph: Draws circular nodes linking database tables and backlog cards.
